TUBE JOB HELPER 0.2.0

NEW TEST: AUTO RUN FILE IMPORT AND CALCULATION OUTPUT WATCH

1. Download from your GitHub repository. Unblock the ZIP in Properties if shown,
   extract into a new folder, and launch Start Helper.cmd.
2. Resume saved job and choose the existing job.json. Keep your CAD/exports where
   they are. Select Assembly Beam2, whose TEOX is already registered.
3. Open Auto Run's Auto Run tab and select TruLaser Tube 7000 (T12). Use a queue
   that does not already contain this test part. Existing saved nests/files do
   not need to be removed. The helper will stop if it detects a duplicate row.
4. Click + in Auto Run. Leave Select TEOX files for import open.
5. Click Import TEOX in Auto Run in the helper. It verifies the context, enters
   the registered path and requests Open, then watches fresh part TPC/TUBX/PDF
   outputs beside that TEOX. Leave TRUMPF's default output location unchanged.
6. Read the status. OutputsVerified means fresh matching output metadata, not
   a machine-ready program. Inspect Auto Run's green check and warnings yourself.

The new handoff is not yet verified on your Windows workstation. If it stops,
leave the Auto Run dialog open and use Save control report. Reports now include
more detail and deeper controls; review them before sharing.

Check calculation outputs resumes watching a recorded request. Stop watching
and a two-minute timeout stop only the helper's watch, not TRUMPF. If TRUMPF
asks a question or shows an error, inspect it yourself; the helper does not
answer unexpected dialogs or select cutting/marking technology for you.

Profile/material confirmation and marking remain your steps. Nesting and final
export remain as before. After calculation, use the existing Nest and check
outputs tab. Use the same helper job name as the intended named nest. Keep the
PDF/TPC beside the TEOX; there is no generated-folder requirement. Review the
PDF and run Check and collect package. A checked copy is placed in deliverables.
Complete your usual TRUMPF simulation and operator release before production.

Existing features retained:
- Original CAD is retained; work on the staged working copy.
- Open Tube Design uses its installed shortcut, never direct sldworks startup.
- Import/Identify have native-toolbar fallback and privilege checks.
- Change helper job name corrects helper metadata without moving/renaming files.
- Resume saved job retains parts, TEOX paths, and metadata.
- No passwords, API authorization, Python install, or network connection needed.
- No automatic USB transfer or machine operation.

If Windows blocks execution after unblocking this exact ZIP, share the message.
Do not disable system policy. Launch uses RemoteSigned for its own process.
See README.md and VALIDATION.md for full behavior and validation limits.
