TUBE DESIGN HELPER 0.3.0 - CAD TO TEOX

Auto Run is paused. This version focuses only on importing STP, STEP or SLDPRT
into Tube Design and getting a TEOX back out. Existing jobs/files are retained.

FIRST TEST
1. Unblock the downloaded ZIP if needed and extract into a new folder.
2. Launch Start Helper.cmd. Resume existing job.json, or choose CAD and prepare
   a new batch. Original CAD is retained separately; work on the staged copy.
3. Open Tube Design normally. Save work and close the current part before
   testing Import working copy. Inspect whether the correct model actually loads.
4. Identify profile and accept the body/material/profile in Tube Design. Apply
   marking/cutting choices. Check the two review acknowledgements in the helper.
5. Click Begin TEOX export. If Tube Design asks to save first, accept that
   prerequisite yourself. In its model-save dialog, click Fill model save dialog
   in the helper. Any overwrite prompt still needs your decision.
6. Review the Export production data selection/settings and click its green
   check in Tube Design. Keep the normal output location beside the input/model.
7. The helper watches the working folder and model-named child folder, checks
   a fresh TEOX, and registers it. Use Check TEOX export after a timeout or
   Register exported TEOX if you used another folder inside this batch.

This is assisted automation. The new import, model-save and export controls
still need their first local Windows test. No CAD-kernel conversion runs in the
cloud, and no profile/marking selections are guessed. A request to import/save
is not a confirmation that Tube Design accepted it.

TEOX checks cover container structure, source model name, units, one geometry,
and a complete binary STL preview. They do not establish engineering geometry
or downstream machine readiness. Old cached output is not treated as a new
export. No TEOX is modified or manufactured by the helper.

If something stops, leave that Tube Design dialog open and use Save control
report. It now captures Tube Design only. Review reports before sharing.
No API password or remote access is needed. No USB transfer or machine command
is performed. Do not change Windows security policy to make scripts run.

See README.md and VALIDATION.md for details. No Python install is required.
